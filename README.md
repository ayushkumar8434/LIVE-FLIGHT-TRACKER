# ✈️ Live Flight Tracker Dashboard

## 📌 Project Overview

The **Live Flight Tracker Dashboard** is a web application that allows users to search and view real-time flight information using a public API.  
It demonstrates API integration, dynamic UI rendering, and the use of JavaScript higher-order functions.

---

## 🎯 Objective

The objective of this project is to:

- Integrate a public API using `fetch`
- Implement search, filtering, and sorting using **Array Higher-Order Functions**
- Build a clean and responsive user interface
- Handle loading and error states effectively

---

## 🌐 API Used

### ✈️ Aviationstack API

live-flight-tracker.netlify.app

- Provides real-time flight data
- Used to fetch flight details such as airline, route, status, and departure time
